# 象棋音效素材

来源分两处：落子音来自 Freesound（CC0，免署名可商用）；吃/将军/绝杀为用户自备音源（man / out / whatcan，M4A）；
终局音来自 https://github.com/BOEING2408/ChessBook （assets/，MIT License）

| 文件          | 用途                                                                               |
| ------------- | ---------------------------------------------------------------------------------- |
| move.mp3      | 落子（Freesound #742356 "SingleKnock_Wood"，CC0，https://freesound.org/s/742356/） |
| capture.m4a   | 吃子（用户自备 "man"）                                                             |
| check.m4a     | 将军（用户自备 "out"）                                                             |
| checkmate.m4a | 绝杀（用户自备 "whatcan"）                                                         |
| win.wav       | 终局/胜利                                                                          |
| invalid.wav   | 非法落点提示（预留）                                                               |

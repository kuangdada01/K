## 1. 交互约定

| 操作           | 当前行为                                                                 |
| -------------- | ------------------------------------------------------------------------ |
| 单击缩略图     | 从对应缩略图展开，黑色背景随转场渐入；图片默认按 Fit 完整居中显示        |
| 单击全屏画面   | 无论是否放大，都关闭查看器；有有效来源时缩回当前图片对应的缩略图         |
| 双击           | 以点击位置为缩放焦点，优先放大至 cover 铺屏；再次双击回到 Fit 居中状态   |
| 单击与双击区分 | 单击等待系统双击判定窗口，避免双击第一下先触发关闭                       |
| 双指捏合       | 1x–4x 缩放，保持手指焦点；放大后可平移，边界按图片实际显示尺寸计算       |
| 横向滑动       | 切换图片；放大图先平移，到边缘后可将剩余横向位移交给分页                 |
| 下拉           | Fit 状态下向下拖动，图片跟手移动、缩小，黑幕逐渐变透；不足关闭阈值时回弹 |
| 返回键         | 一次请求关闭；从当前可见状态退出，动画完成后释放查看器                   |
| 长按           | 打开现有媒体保存弹层，保留图片请求所需鉴权头                             |
| 多图指示       | 底部圆点显示当前页；单图不显示圆点                                       |

双击目标倍率按图片与容器宽高比计算，并限制在 1x–4x。图片与屏幕比例接近、
或者图片比例尚未知时，使用 2.5x；极宽或极长图片受到 4x 上限约束，不能保证完全铺满。

当前下拉与动画参数：

- 进场、退场为 **250 ms**；图片使用 `KMotion.standard` 缓动，背景使用独立的 smoothstep 透明度映射。
- 双击缩放使用 `KMotion.medium`，当前为 260 ms；允许新手势从动画当前帧接续。
- 下拉距离超过屏高的 1/6，或超过触摸阈值且向下速度大于 1200 px/s 时提交关闭。
- 下拉缩放最低为 0.75，背景透明度最低为 0.5；关闭过程再从当前黑度渐隐。
- 下拉回弹为 200 ms，分页吸附为 220 ms；甩动落点最多为手势开始页的相邻一页。

## 3. 转场与手势如何衔接

### 打开、查看、关闭

`ImageViewerOverlay` 使用独立全屏 Dialog，单独管理状态栏。设计目的是避免为了看图隐藏状态栏时，
改变底层信息流的布局与缩略图位置；不同系统版本的窗口坐标和系统栏表现仍需真机检查。

查看器分为 `Opening → Ready → Closing` 三个阶段。每段进出场持有自己的动画时钟，
返回键可从尚未完成的进场画面开始退出。进出场期间拦截新的触摸操作。

打开动画结束后必须交接到可缩放图片层，并撤掉可见的转场图。图片成功或失败都会报告就绪，
交接等待最多再延长 100 ms，避免加载失败时永久停留在转场层。转场使用的 painter 仍保留在组合中，
为关闭时复用，减少退出首帧重新加载造成的空白。

关闭时重新解析当前图片的缩略图来源，并把图片当前缩放、平移、下拉变形计入退场起点。
动画完成后调用 `onClosed(index)`，由调用方处理页码同步。

### 固定触摸平面

触摸检测放在不缩放的全屏容器上，图片层单独应用下拉和缩放变换。
这样放大图片后，手指位移仍以屏幕像素计算，不会被图片自身的缩放再次换算。

拖动、捏合与分页通过一个拖动状态机协调；单击、双击和长按交给点击检测器。
平移边界由 **Fit 后的真实图片尺寸**计算，避免把横图上下的黑边也当成可平移内容。
动画取消时保留当前帧，不在取消后的清理逻辑里跳到旧目标。

下拉向宿主报告累计位移。新的触摸只有实际接管对应拖动时才取消宿主回弹；
单击、双击不会单纯因为按下而把图片冻结在半页或缩小状态。

### 加载与降级

- 图片通过 Coil 3 加载，传递 `NetworkHeaders`，并使用缩略图内存缓存作占位。
- 解码请求尺寸依据屏幕长边确定；当前页预加载与查看器使用相同请求构造函数。
- 转场图片使用 `ImageLoading.immediate`，避免被普通图片的动画让路机制阻塞。
- 无有效来源矩形、来源已移出可见区域或宽高比未知时，使用淡入/淡出。
- 关闭时分页仍有明显偏移，保留原分页画面整体淡出，避免邻页突然消失。
- 加载失败显示“图片加载失败”，仍可单击或返回关闭。
- 关闭动画设置时立即落位或退出；当前实现没有旧网页的 `localStorage.k_viewer_hero` 开关。

## 4. 本次修正的问题

| 原问题                                 | 修正                                 |
| -------------------------------------- | ------------------------------------ |
| 进场结束后静态转场图仍盖在可操作图片上 | 明确切换到 Ready，移交显示与手势     |
| 缩放图片同时改变触摸坐标               | 分离固定触摸平面和变换后的图片层     |
| 平移边界按整屏而非实际图片计算         | 按 Fit 后图片尺寸约束平移            |
| 下拉只使用单帧增量，图片不跟手         | 向宿主报告累计位移                   |
| 取消缩放动画后跳到旧目标               | 保留取消时的实际变换                 |
| 放大图边缘交给分页后没有吸附收尾       | 接力后进入分页模式，并处理结束与取消 |
| 回弹中再次触摸可能冻结中间状态         | 实际拖动接管时才取消对应宿主动画     |
| 半页位置关闭时邻图突然消失             | 使用整体淡出，保留分页裁剪与可见内容 |

这些条目记录源码修改及审查结论，视觉效果仍以完成下面的真机验收为准。

## 6. 真机验收清单

以下各项均为**待验收**；历史版本的通过记录不代表本次重写已通过。

1. 在帖子详情、信息流/主页入口、私信图片中分别单击打开；检查来源位置、圆角、渐变黑幕和末帧交接。
2. Fit 与放大状态各单击一次，检查均关闭；返回键也应一次退出。
3. 连续双击：首次放大、再次还原，不触发关闭，不先缩回缩略图再弹入。
4. 用横图、竖图、长图和接近屏幕比例的图片检查双击目标、焦点位置与平移边界。
5. 捏合过程中移动双指、抬起其中一指继续拖动，检查不跳变、不误关闭。
6. 多图连续滑动、放大图到边缘继续横滑，检查分页最终吸附和底部圆点。
7. 下拉未达阈值松手应回弹；超过阈值或快速下甩应关闭，松手时黑幕不突然变黑。
8. 分页吸附或下拉回弹未结束时再次单击、双击、拖动，检查没有半页或缩小状态残留。
9. 半页位置请求关闭，检查整幅分页画面平滑淡出；完全停稳时应缩回当前图片来源。
10. 来源缩略图重排、离屏或不存在时检查落点与降级；入口提供回调时检查关闭页码。
11. 长按保存公开图片和需要鉴权的私信图片；检查弹层位于查看器上方。
12. 断网/坏链接后仍能退出；连续开关、进场途中返回、切换系统导航方式时没有黑窗、触摸穿透或系统栏残留。
